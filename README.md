# Display Off — эксперимент 0.1.0

Android 11+, целевое устройство Redmi Note 13 Pro / HyperOS. Самостоятельный APK, использует встроенный ADB-клиент (libadb-android 3.1.1, Conscrypt, Bouncy Castle). Подключение только к 127.0.0.1. Не требует root или дополнительных приложений. Нет произвольного терминала.

**Риск:** физическое выключение через скрытый SurfaceControl API зависит от прошивки. Ни таймер, ни повтор команды включения не гарантируют восстановление. Не использовать во время важных задач. При отсутствии изображения попробовать кнопку питания, затем удерживать её для принудительной перезагрузки. Не проверялось на целевом устройстве.

## Тест
1. Включить режим разработчика и беспроводную отладку.
2. В разделённом экране открыть окно сопряжения по коду и приложение. Ввести порт сопряжения и код.
3. Ввести отдельный основной порт отладки и нажать подключение. Проверка отправляет только команду ON.
4. Нажать тест, подтвердить предупреждение. Shell-процесс запускается отдельно от интерфейса. Перед OFF подготавливается второй процесс восстановления. Основной таймер 10 секунд, резервный 15 секунд от готовности. Оба повторяют ON. Если API не удаётся разрешить, есть несколько физических дисплеев или резервный процесс не готов — OFF не вызывается.
5. Сравнить реальное состояние экрана с журналом; успешный вызов API не доказывает физическое восстановление. После проверки отключить беспроводную отладку и при необходимости удалить сопряжение.

В этой версии нет автоматического обнаружения YouTube и нет длительного отключения. Не изменяются системные параметры сна. Приложение не отправляет данные на внешние серверы. Ключ ADB хранится в приватном каталоге приложения без резервного копирования.

## Сборка
GitHub Actions → Build test APK → Artifacts. APK отладочный. Механизм Android 14 основан на общедоступном API-подходе scrcpy (Genymobile, Apache-2.0), см. https://github.com/Genymobile/scrcpy . Библиотеки: https://github.com/MuntashirAkon/libadb-android , https://github.com/google/conscrypt , https://www.bouncycastle.org/ .
